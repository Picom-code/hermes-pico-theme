# Pico — Hermes Agent skin

Neon pink on pure black, concise and a little kawaii. Chibi anime-girl banner, PICO block logo,
short spinner verbs with kaomoji.

![Pico startup banner](screenshots/banner.png)

![Pico chat view](screenshots/chat.png)

## Install

```sh
mkdir -p ~/.hermes/skins
cp pico.yaml ~/.hermes/skins/
hermes skin use pico
```

Or try it in a session with `/skin pico`.

Best on a pure black terminal background. The PICO logo only shows at 95+ columns.
